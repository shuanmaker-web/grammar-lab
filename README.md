# Grammar Lab

英文文法教學板:老師在 iPad 上用拖曳方塊,把文法結構「看」出來,給文法基礎弱的學生用。

## 模式
- **步驟示範**(主題 12 以外):按「下一步 ▶」,句子一列一列往下變化(例:肯定 → 否定 → 疑問;主動 → 被動;兩句 → 合成一句)。有外框的方塊 = 和上一步不同的地方。每一列的方塊都可以拖曳。
- **兩句合一句**(主題 12 關係子句):① 標出相同的人/物 ② 點代名詞換成關代 ③ 把關係子句拖到先行詞後面。
- **自由排列**(所有主題):完整句子的方塊可自由拖曳;「打散」隨機打亂、「還原」回正確語序;排對顯示 ✓。步驟示範的主題可以點上方的步驟,選要排哪一句。

## 畫面操作
- 「選單」→「‹ 所有主題」切換主題;選單裡點句子直接跳過去
- 「標籤」「顏色」可關掉,讓學生自己判斷;A− / A+ 調字級
- 色碼:主詞(藍)、動詞(綠)、受詞(黃)、補語(青)、修飾語(紫)、助動詞(粉)、否定(灰)、連接詞(棕)、疑問詞/關代(珊瑚紅)、子句/片語(紅虛線框)

## 新增句子
### 一般主題(`data-basic.js` / `data-verbs.js` / `data-clauses.js`)
```js
I('b01', [
  s('肯定句', 'S:he | V(be動詞):is | C:a student', '講解文字'),
  s('否定句', 'S:he | V(be動詞):is | *N:not | C:a student', '講解文字'),
  s('疑問句', '*V(be動詞):is | S:he | C:a student ?', '講解文字', ['也可以這樣說的句子'])
])
```
- 方塊用 ` | ` 分開,每個方塊 = `角色:文字`。角色:`S` 主詞 `V` 動詞 `O` 受詞 `C` 補語 `M` 修飾語 `X` 助動詞 `N` 否定 `J` 連接詞 `Q` 疑問詞
- `V(be動詞):is` → 括號內是自訂標籤
- 前面加 `*` → 這一步新出現/有變化(加外框)
- `[副詞子句: J:when | S:I | V:got | M:home],` → 中括號是可整組拖曳的框;結尾逗號只在它不是句尾時顯示
- 結尾加 ` ?` 或 ` !` → 句尾標點
- 第 4 個參數:自由排列時也算對的其他說法
- 完整說明在 `data-core.js` 開頭

### 關係子句(`data.js`)
每句 = 句子 A(含先行詞 `ANT`)+ 句子 B(含一個 `P` 代名詞):
```js
{ id: 'r23',
  A: [ANT('the man'), V('is'), C('my teacher')],
  B: [P('he', ['who', 'that'], '主詞'), V('lives'), M('next door')],
  note: '講解文字' }
```
`P(原代名詞, [關代選項…], 功能, {front, omit})`;`comma: true` 非限定用法;`also: [...]` 其他可接受說法。
